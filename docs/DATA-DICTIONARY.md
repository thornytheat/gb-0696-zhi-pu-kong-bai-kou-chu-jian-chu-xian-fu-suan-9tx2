# 质谱字段与规则

sample_id保留前导零。kind取standard、blank、sample、control。area与internal_area为峰面积。level为标样浓度，单位支持ug/L、mg/L、ng/L；统一为ug/L。dilution必须大于0。

每批每检测项至少3个独立浓度点。最小二乘使用Decimal，分母为零拒绝；斜率非正拒绝。空白取同批同项的浓度中位数。净浓度允许为负；不能提前截零。稀释后检出限=0.05×倍数。控制样相对误差超过20%阻断。超过标曲响应范围优先于其他质控判断。

重复编号相同内容标DUPLICATE，不同内容标KEY_CONFLICT。采信包括标曲和空白，最终样品数不等于输入采信数。行数对账独立于样品结果数。

同一批次同一分析项内sample_id唯一；相同样品编号可在不同分析项或批次中复用。

## 补交更正

补交文件只需含待补的样品行（带表头），以 batch+analyte+sample_id 为业务键并入原批次，不产生新批次。

- 已生效：该样品尚未复核，补交行替换原行并进入现行结果，样品回到待复核。标曲或空白的补交即使不改样品行，也标记为已生效并提示相关样品需复核。
- 停在原结论：该样品已复核，原结论与被替换行依据完整保留，补交内容仅入合并记录与证据导出；该补交行不进入现行账本，不改变标曲与空白的复算基础。补交行本身不合格时同样停在原结论，并附隔离原因。补交标曲或空白导致其他已复核样品计算值变化时，这些样品也标为停在原结论并注明「受本次补交影响」，不会静默改动。
- 内容一致：补交内容与现行结论相同，无实质变化。
- 仍隔离：补交行仍未通过校验，只进入隔离记录。

同一补交内容（规则版本+文本摘要）重试不新增版本。合并失败（不可解析、无可采信行、复算异常、版本冲突）时不写入任何内容，旧版结果与版本号保持不变。
